# Macn Launcher

## Описание

Macn Launcher — современный высокопроизводительный модульный десктопный лаунчер для Minecraft: Java Edition с открытым исходным кодом, разработанный на платформе Java 21 LTS с использованием UI-фреймворка JavaFX 21 и библиотеки тем оформления AtlantaFX. Приложение реализует полный и автономный жизненный цикл управления версиями Minecraft: прямое взаимодействие с официальными API Mojang, валидацию и разрешение правил совместимости библиотек для целевых платформ, многопоточную асинхронную загрузку ассетов с контролем целостности по алгоритму SHA-1, автоматическую проверку и изоляцию сред исполнения Java Runtime, а также запуск игровых клиентов с маскированием конфиденциальных данных.

Проект решает задачи устранения задержек интерфейса при перемещении окон за счет нативной интеграции с DWM Windows и VSync-коалесценции при частоте до 240 Гц, предоставления унифицированного интерфейса для официальной авторизации Microsoft OAuth 2.0 (Device Code Flow) и скинов Ely.by через инжекцию authlib-injector, поддержки классических версий игры через мост LegacyLaunchBridge, а также обеспечения встроенного мониторинга ресурсов с веб-интерфейсом и кастомного клиента Fabric с монохромным графическим интерфейсом Cosmic UI.

## Технический стек

- **Java 21 LTS**: Основной язык разработки лаунчера, бизнес-логики, алгоритмов сетевого взаимодействия и управления дочерними процессами (параметр сборки `release 21`).
- **JavaFX 21.0.4 (`javafx-controls`, `javafx-fxml`, `javafx-graphics`, `javafx-base`)**: Графическая оконная подсистема пользовательского интерфейса, разметка FXML и аппаратно-ускоренный рендеринг компонентов.
- **AtlantaFX 2.0.1 (`atlantafx-base`)**: Библиотека векторных тем оформления (поддержка `PrimerDark`, `PrimerLight`, `Pure Black`, а также палитр `Crimson Noir`, `Cyber Acid`, `Editorial Contrast`, `Electric Deep`, `Geometric Light`, `Rust Earth`).
- **JNA 5.14.0 (Java Native Access)**: Низкоуровневые вызовы функций Win32 API (`User32`, `Dwmapi`) для аппаратного перехвата перетаскивания окна без задержек через сообщения `WM_NCLBUTTONDOWN` и `HTCAPTION`.
- **Jackson Databind & JSR310 2.17.2**: Высокопроизводительная потоковая обработка и сериализация/десериализация JSON-метаданных, манифестов версий Mojang, конфигураций и профилей.
- **Java HTTP Client (`java.net.http.HttpClient`)**: Асинхронный сетевой стек ядра с поддержкой протокола HTTP/2, пулом виртуальных/демон-потоков и настраиваемой политикой экспоненциальных повторов (Retry Policy) с джиттером.
- **SLF4J 2.0.13 и Logback Classic 1.5.6**: Подсистема логирования с ротацией лог-файлов по времени и объему, а также перехватом консольного вывода запущенной игры.
- **Fabric Mod Loader & Fabric API (1.21.11 / 1.21.1)**: Подсистема загрузки модов в подпроекте `macn-cosmic-gui-1.21.11-fabric-src` с миксинами (`macncosmicgui.mixins.json`) для кастомизации интерфейса Minecraft.
- **Web UI Bridge (TypeScript, Tailwind CSS, shadcn/ui)**: Встроенный локальный HTTP-сервер на базе `com.sun.net.httpserver.HttpServer`, транслирующий метрики потребления ресурсов (`/api/resources`) и диаграммы архитектуры в реальном времени.
- **Apache Maven 3.9+ & Plugins**:
  - `maven-compiler-plugin 3.13.0`: Компиляция под Java 21 с кодировкой UTF-8.
  - `maven-shade-plugin 3.6.0`: Создание исполняемого Fat JAR со всеми встроенными зависимостями (`macn-launcher-1.0.0-all.jar`).
  - `launch4j-maven-plugin 2.5.1`: Автоматическая сборка нативного исполняемого файла Windows `MacnLauncher.exe` с векторной иконкой `Logo1.ico`.
  - `javafx-maven-plugin 0.0.8`: Запуск лаунчера в среде разработки.
- **JUnit 5 (Jupiter 5.10.2)**: Каркас автоматизированного модульного и интеграционного тестирования компонентов.

## Ключевые особенности / Архитектура

### Модель запуска без модульных конфликтов JPMS
Приложение использует шаблон развязки точки входа: класс `com.macnlauncher.Main` содержит стандартный статический метод `main(String[] args)`, делегирующий вызов `Application.launch()` классу `com.macnlauncher.LauncherApplication`. Это исключает проверку наличия модулей JavaFX со стороны JVM при старте, позволяя распространять приложение в виде единого самодостаточного Shaded JAR (`macn-launcher-1.0.0-all.jar`) и запускать его стандартной командой `java -jar`.

### Аппаратная оптимизация перемещения окна (240 Hz DWM Coalescing)
Для устранения падения частоты кадров и микрофризов (stuttering), возникающих при непрерывном вызове `Stage.setX()` / `Stage.setY()` из событий мыши с частотой 1000 Гц, компонент `NativeWindowDrag`:
- В среде Windows использует JNA для передачи управления перемещением непосредственно оконному менеджеру Desktop Window Manager (DWM) через отправку Win32-сообщения `WM_NCLBUTTONDOWN` с параметром `HTCAPTION`.
- В кроссплатформенном fallback-режиме накапливает координаты в буфере и применяет их строго в цикле `AnimationTimer`, синхронизированном с кадровой частотой монитора (VSync coalescing до 240 кадров/с).
- Поддерживает кеширование узлов графического графа (`CacheHint.SPEED`) на время активного движения.

### Жизненный цикл версий и сетевой загрузчик
- **Разрешение манифеста**: Обработка официального манифеста `version_manifest_v2.json` с классификацией выпусков (`release`, `snapshot`, `old_beta`, `old_alpha`) и локальным кэшированием.
- **Анализ зависимостей (`LibraryResolver`)**: Вычисление системных правил (`rules`) по операционной системе (`windows`, `linux`, `osx`), архитектуре (`x86`, `x86_64`, `arm64`) и системным свойствам; разделение общих JAR и платформенных нативных библиотек.
- **Распаковка нативов (`NativeLibraryManager`)**: Потоковое извлечение динамических библиотек (`.dll`, `.so`, `.dylib`) с фильтрацией исключений `extract.exclude` и строгой защитой от атак выхода за пределы целевого каталога (Zip Slip validation).
- **Многопоточный `DownloadManager`**: Ограничение конкурентных сетевых потоков через `Semaphore`, потоковая запись во временные файлы с суффиксом `.part`, верификация размера и хеш-суммы SHA-1 перед атомарным перемещением, экспоненциальный откат при сбоях (коды 408, 429, 5xx).
- **Обработка ресурсов (`AssetResolver`)**: Загрузка индекса ассетов и парсинг структуры хешей объектов для загрузки по схеме Mojang `first2/sha1`.

### Контроллер процесса игры и защита данных
- **Формирование аргументов (`LaunchService`)**: Поддержка современного формата аргументов (`arguments.jvm` и `arguments.game`), а также устаревшего строкового шаблона `minecraftArguments`; автоматическое разрешение цепочек наследования конфигураций (`inheritsFrom`).
- **Изоляция и валидация Java**: Сервис `JavaRuntimeService` анализирует установленные JVM и сопоставляет их с полем `javaVersion.majorVersion` запускаемой версии (Java 21 для Minecraft 1.20.5+, Java 17 для 1.18–1.20.4, Java 8 для релизов до 1.16.5).
- **Безопасность логов (`GameLogReader`)**: Потоковое асинхронное чтение потоков `stdout` и `stderr` процесса Minecraft с автоматической фильтрацией и маскированием токенов сессий, паролей и персональных идентификаторов (`[REDACTED]`).
- **Интеграция скинов и авторизации**:
  - Microsoft OAuth 2.0 Device Code Flow: получение авторизационного кода, обмен на токены Xbox Live, получение XSTS-токена и авторизация в сервисах Minecraft (`api.minecraftservices.com`).
  - Поддержка скинов Ely.by: динамическая загрузка и аргументная инжекция агента `-javaagent:authlib-injector.jar=ely.by`.
  - Мост устаревших версий (`LegacyLaunchBridge`): обеспечение корректного запуска старых альфа/бета версий на современных сборках Java (17/21).

### Монохромный интерфейс Cosmic UI и Fabric-мод
- **Лаунчер**: Рендеринг процедурного звездного поля на JavaFX Canvas (`CosmicBackground`) с разделением на 4 слоя глубины, синусоидальным мерцанием звезд и LUT-интерполяцией цвета кнопок (`AnimatedButton`) от `#0A0A0A` до `#F5F5F5`.
- **Внутриигровой клиент**: В директории `macn-cosmic-gui-1.21.11-fabric-src` содержится исходный код Fabric-мода для Minecraft 1.21.1/1.21.11, заменяющий стандартные экраны главного меню, настроек, одиночной и сетевой игры на минималистичный монохромный интерфейс с размытием фона и кастомными векторными шрифтами (`cosmic-sans.ttf`).

## Требования

### Требования к сборке (Build-time)
- **Операционная система**: Windows 10/11 (x64), Linux (x86_64), macOS 11+ (x86_64, Apple Silicon).
- **Java Development Kit (JDK)**: Версия **21 LTS** или выше (64-бит). Рекомендуется Eclipse Temurin 21 или Oracle JDK 21.
- **Apache Maven**: Версия **3.9.0** или выше (поддерживается встроенный сборщик IntelliJ IDEA).
- **Сетевой доступ**: Доступ к репозиториям Maven Central, Mojang API (`launchermeta.mojang.com`, `piston-meta.mojang.com`, `resources.download.minecraft.net`) и Microsoft Login.

### Требования к запуску (Runtime)
- **Среда выполнения (JRE/JDK)**: Java Runtime Environment 21 (64-бит) для самого лаунчера.
- **Дополнительные среды Java**:
  - Java 8 (x64) — для запуска версий Minecraft 1.0 — 1.16.5.
  - Java 17 (x64) — для версий Minecraft 1.17 — 1.20.4.
  - Java 21 (x64) — для версий Minecraft 1.20.5+.
- **Оперативная память**: Не менее 4 ГБ физической памяти (рекомендуется 8 ГБ и более для комфортного запуска игры с модами).
- **Видеокарта**: Графический адаптер с аппаратной поддержкой OpenGL 3.2+ и актуальными драйверами.

## Установка и запуск

### 1. Клонирование репозитория
Откройте терминал и выполните клонирование проекта:
```bash
git clone https://github.com/example/MacnLauncher1121.git
cd MacnLauncher1121
```

### 2. Проверка версии Java
Убедитесь, что установлена и активна 64-битная версия JDK 21:
```bash
java -version
javac -version
```
При необходимости задайте переменную среды `JAVA_HOME`:
```powershell
# Для Windows PowerShell:
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.4.7-hotspot"
$env:Path = "$env:JAVA_HOME\bin;" + $env:Path
```

### 3. Запуск тестов
Для проверки целостности компонентов, резолверов библиотек и метрик запустите набор тестов JUnit 5:
```bash
mvn clean test
```

### 4. Запуск приложения в режиме разработки
Для запуска интерфейса напрямую из исходного кода без создания бинарного дистрибутива:
```bash
mvn javafx:run
```

### 5. Сборка автономного исполняемого JAR (Fat JAR)
Скомпилируйте проект и упакуйте исполняемый Shaded JAR со всеми зависимостями:
```bash
mvn clean package -DskipTests
```
Готовый автономный файл будет расположен в каталоге `target/`:
- `target/macn-launcher-1.0.0-all.jar` (~16 МБ).

Запуск собранного JAR-файла:
```bash
java -Dfile.encoding=UTF-8 -jar target/macn-launcher-1.0.0-all.jar
```

### 6. Сборка нативного Windows EXE (`MacnLauncher.exe`)
При наличии Windows-окружения сборка нативного исполняемого файла с встроенной иконкой `Logo1.ico` выполняется автоматически в ходе фазы `package` через плагин Launch4j, либо с помощью командного файла:
```cmd
build-exe.bat
```
Исполняемый файл создается по путям:
- `target/MacnLauncher.exe`
- `MacnLauncher.exe` (в корневом каталоге проекта)

Прямой запуск скомпилированного бинарного файла:
```powershell
.\MacnLauncher.exe
```

## Управление / Использование

### Навигация и разделы лаунчера
- **Главная (Home)**: Отображение текущего выбранного профиля, индикатор статуса версии, переключатель аккаунта, системная информация о памяти и кнопка запуска игры («Играть» / «Установить»).
- **Версии (Versions)**: Таблица официальных релизов, снапшотов и бета-версий Minecraft с поиском по названию, фильтрацией по категориям и отображением статуса локальной загрузки.
- **Установки (Installations)**: Создание и редактирование пользовательских профилей игры. Настройка индивидуального рабочего каталога, переопределение исполняемого файла Java и параметров JVM (`-Xms`, `-Xmx`, аргументы GC).
- **Аккаунты (Accounts)**: Авторизация учетной записи. Поддержка Microsoft OAuth 2.0 (вход по коду устройства), интеграция скинов Ely.by и локальный режим разработчика (`--demo`).
- **Настройки (Settings)**: Управление выделением оперативной памяти (ползунки минимальной и максимальной памяти), выбор темы оформления (AtlantaFX PrimerDark, PrimerLight, Pure Black и цветовые акценты), переключение языка интерфейса (RU, UK, EN), управление фоновыми анимациями и портом встроенного Web UI.
- **Монитор ресурсов (Resources)**: Встроенная аналитика потребления памяти, потоков и времени обработки модулей с возможностью экспорта графической схемы в формате PNG.
- **Консоль (Console)**: Просмотр журнала вывода запущенного игрового процесса в реальном времени с функцией копирования и очистки.

### Управление окном
- **Перемещение окна**: Зажатие ЛКМ на верхней панели заголовка плавно перемещает окно приложения (аппаратная синхронизация 240 Гц).
- **Разворачивание окна**: Двойной клик ЛКМ по панели заголовка разворачивает окно на весь экран либо возвращает его к исходному размеру (1040x680 пикселей).
- **Кнопки управления**: В правом верхнем углу расположены кнопки сворачивания, разворачивания и закрытия окна приложения.

### Расположение рабочих файлов и конфигураций
Лаунчер изолирует игровые данные от системных файлов. Конфигурации хранятся в домашней директории пользователя:
- **Windows**: `%APPDATA%\.macnlauncher\`
- **Linux**: `~/.macnlauncher/`
- **macOS**: `~/Library/Application Support/macnlauncher/`

Структура каталога данных:
- `config/settings.json` — глобальные настройки лаунчера;
- `config/profiles.json` — конфигурация созданных профилей и установок;
- `config/accounts.json` — сохраненные профили учетных записей (токены доступа хранятся в защищенном виде);
- `cache/version_manifest_v2.json` — локальный кэш манифеста версий Mojang;
- `logs/macnlauncher.log` — текущий лог работы лаунчера;
- `minecraft/` — изолированный каталог игровых данных (`versions/`, `libraries/`, `assets/`, `natives/`).
