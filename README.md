# MacnLauncher

MacnLauncher — это легковесный и модульный лаунчер для Minecraft, написанный на Java и JavaFX. Проект спроектирован с упором на максимальную производительность, строгий минималистичный дизайн и аппаратную изоляцию игровых клиентов.

## Архитектура и производительность
* **Оптимизация потребления ОЗУ:** В активном режиме лаунчер потребляет до 300 МБ оперативной памяти.
* **Zero-overhead режим:** Доступна опция полного завершения процесса лаунчера при запуске Minecraft для высвобождения системных ресурсов.
* **Многопоточный движок загрузок:** Собственная реализация `DownloadManager` обеспечивает параллельное скачивание версий, библиотек и игровых ассетов.

## Пользовательский интерфейс (UI/UX)
* **Borderless Design:** Окно без системных рамок с использованием `NativeWindowDrag` для плавного перемещения интерфейса без фризов.
* **Система темизации:** Интегрированы встроенные цветовые CSS-палитры (Pure Black, Cyber Acid, Crimson Noir, Electric Deep, Rust Earth) с поддержкой темного и светлого режимов.
* **MorphIcons:** Использование собственной системы легковесных иконок и CSS-анимаций для обеспечения отзывчивости графического интерфейса.

## Мониторинг и Web-интерфейс
* **Аналитика в реальном времени:** Подсистема `ResourceMetricsService` с рендерингом диаграмм отслеживает нагрузку на CPU, RAM и дисковую подсистему во время работы приложения.
* **Web-панель управления:** Интегрирован локальный `WebUiServer`, предоставляющий современный дашборд (React + Tailwind CSS) для удаленного контроля и просмотра логов.

## Управление игрой и изоляция
* **Умный установщик:** Модули `VersionInstaller` и `LibraryResolver` автоматически загружают и валидируют зависимости для Vanilla, Forge и Fabric.
* **Изолированные директории:** Каждая сборка имеет собственную файловую среду, что на системном уровне исключает конфликты модификаций при переключении между профилями.
* **Менеджмент Java Runtime:** `JavaRuntimeService` автоматически подбирает и настраивает требуемую версию Java в зависимости от версии запускаемого клиента Minecraft.

## Интеграции
* **Ely.by Auth:** Нативная поддержка авторизации через систему Ely.by с автоматической синхронизацией профилей и скинов.
* **Discord Rich Presence:** Интеграция по протоколу Discord RPC для трансляции текущего игрового статуса и запущенной версии в профиль пользователя.
